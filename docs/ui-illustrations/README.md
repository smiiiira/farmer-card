# Иллюстрации интерфейса

Сюжеты UI подготовлены по действующим JSX/CSS-компонентам проекта и показывают учебный сценарий заполнения из искусственной тестовой этикетки. Это **не скриншоты фактически запущенного приложения**, а статичные иллюстрации состояний. Для защиты можно заменить их реальными скриншотами после запуска локального приложения.

Чтобы получить реальные скриншоты: `npm.cmd ci` → `npm.cmd run dev`, затем последовательно: (1) загрузите `examples/TEST_russian_composition.png`; (2) распознайте и проверьте строки; (3) заполните название вручную, откройте предпросмотр и подтвердите сверку с упаковкой. На Windows сохраните экран `Win + Shift + S`.
