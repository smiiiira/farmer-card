# Проверки и ограничения MVP

Дата подготовки: 29 октября 2026 года.

## Автоматические проверки

Команда `npm test`: 11 unit-тестов после добавления `cardEngine.test.js` (6 для OCR, 5 для формирования карточки). Проверены шумовые строки из реальных обращений, выбор попытки OCR, отсутствие догадок, правила извлечения полей, недостающие обязательные поля, оценка заполненности и описание.

## Примеры OCR (из предшествующего прогона)

| Случай | Наблюдение |
|---|---|
| Фото банки без этикетки | Шум отфильтрован; «надёжный текст не обнаружен» |
| Декоративная надпись «Дальневосточный мёд малиновый» | Не получен уверенный текст; нужен ручной ввод |
| Синтетическая печатная этикетка | Прочитаны состав, масса и изготовитель |

Это **три качественных случая**, не статистика точности и не доказательство 3-минутного времени работы.

## Не проверено автоматически

- На реальных разных упаковках нет набора размеченных эталонов для CER/WER.
- В текущей среде не подтверждена полноценная браузерная сборка и развертывание; CI на GitHub должен проверить `lint`, `test`, `build`.
- Нет официальной модерации, классификатора категории или подключенного REST API.
